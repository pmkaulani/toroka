# Toroka (formerly Smart Scam Identifier)

**What:** Kenya-first checker you talk to like a chat AI. Returns evidence, dates and gaps, and says when a site or shop is verified while giving context-specific payment guidance.
**State (2026-10-22):** chat UI built; verified-entity records and policy v0.3; 224 Python tests, 37 real-browser tests, 31 evaluation cases. Not yet run against real third-party services, PostgreSQL, real devices or real users.
**Blocked on people and accounts:** counsel and data-protection advice, interviews, registry and verified-record human review, API credentials, WhatsApp/SMS approvals, a delivery worker for codes, Figma approval.
**Principles:** no accusations; list what was not checked; verified means the site, never the offer; official statements dated and reviewed; message text is data; encrypted short retention; moderated indicators only.
